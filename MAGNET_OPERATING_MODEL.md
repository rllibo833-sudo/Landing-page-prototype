# PUBLIC MAGNET OPERATING MODEL

PUBLIC is the human-facing front door of the three-repository ecosystem.

Its magnet function is to help a real person understand:
1. what this ecosystem is;
2. why it matters;
3. what capability already exists;
4. what evidence exists;
5. what needs are welcome;
6. how to request help or propose collaboration;
7. how qualification and Founder Gate work.

The public path is:

**DISCOVER → UNDERSTAND → SEE EVIDENCE → REQUEST / CONTRIBUTE → QUALIFY → FOUNDER GATE → REAL OUTPUT → PROOF**

PUBLIC must attract qualified people, real needs, contributors, collaborators and opportunities — not empty traffic.

See the Founder Memory repository for the durable Day 5 operating model and the full three-repository magnet model.
