# Kawasan Masjid 1.000 Ha — Public Website

Public discovery layer for the Kawasan Masjid 1.000 Ha project.

Architecture: Founder AI Memory → Project OS / Supabase → Public Website.

The website is intentionally smaller than Project OS: storytelling, vision, ecosystem, live public evidence and participation only.

Run: `npm install && npm run dev`
Build: `npm run build`

GitHub Pages deploys from `main`.
